## 1. 环境与陷阱（踩过的，别再踩）

| 陷阱 | 事实 | 应对 |
| --- | --- | --- |
| **`/tmp` 在 DSH 沙箱下写受限** | 直接 `bun test __tests__` 会假红约 20 例（`SQLITE_CANTOPEN` / `mcp-http`） | 一律 `TMPDIR="$PWD/.cogmem/tmp" bun test __tests__` |
| **本机 `git fetch` 会静默失败** | `unable to get credential storage lock: Permission denied`；本地 `origin/...` ref 会过期，`git status` 谎报「领先 18」 | 用 `git ls-remote origin refs/heads/<branch>` 核实；push 本身是成功的 |
| **验证 CI 真实行为要清空 HOME** | 本机 `~/.cogmem/config.toml` 会替本该隔离的用例兜底，造成「本地绿、CI 红」 | 再跑一遍 `E=$(mktemp -d); TMPDIR=/tmp HOME="$E" bun test __tests__` |
| **生成的插件是 `String.raw` 模板** | 模板内注释里出现**反引号**会终止模板，报 `TS1005` | 模板内的注释不要用反引号 |
| **`dist/` 被 git 跟踪** | 改 `src/` 后必须 `bun run build` 并提交 `dist/`，否则 CI 的 dist 一致性测试会红 | 每次改 src 后跑 build 并 `git add dist` |
| **工具 schema 真的会变** | 改 MCP 工具集后，`__tests__/release-metadata.unit.test.ts` 会从真实注册表算 core/admin/full 计数并与 README/CHANGELOG 文本比对 | 同步改 `docs/mcp-hosts.md`、`README.md`、`CHANGELOG.md` 里的数字 |
| **`docs/overnight-progress.md` 是 gitignored 草稿** | 不属于交付物，新克隆没有它 | 持久结论写进本文件或 GitHub |

### 4.2 #65 — 身份隔离

已核实问题点：
- `src/mcp/server.ts` 身份合并 `hostId: override.hostId ?? base.hostId` —— header 可自报 hostId（只有 profile 受 `identityTrusted` 限制）。
- `src/mcp/http.ts` 只有一个可选全局 Bearer token，回环可不带；全局 token 只证明「能访问」，不证明「是哪个智能体」。

方向：每个接入的智能体在服务端登记并持有凭证；hostId 由连接/凭证决定；请求字段只能收窄或拒绝；MCP 路径与 bridge/插件路径共用同一身份逻辑；登记与凭证位置写进 ADR。**不要破坏单宿主默认安装流程。**
